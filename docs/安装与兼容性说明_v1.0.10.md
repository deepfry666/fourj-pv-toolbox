# 四季光伏工具箱 v1.0.10 安装与兼容性说明

- 版本：v1.0.10 / 1.0.10.0，上一稳定版 v1.0.9；支持 AutoCAD 2020 Win64 R23.1，正式负载六个 DLL。
- 安装器和 DLL 没有 Authenticode 签名，发布分类 UNSIGNED、签名预期 NotSigned；Windows 可能显示“未知发布者”，应核对本仓库来源及同版 SHA-256。
- 保存并备份图纸，完全退出 AutoCAD、探索者和 Core Console，运行 FourJ_PV_Toolbox_Setup_v1.0.10.exe，选择与旧版相同的安装范围。
- 本版修复缓存故障导致的翻译中断，不重置用户工程参数、API 配置或缓存；坏条目和过长内容只跳过缓存，其他有效译文继续可用。
- 保留长英文排版保护：字高最低为原值 75%，空间不足保留该项原文；弧线、复杂曲线和非共面模型仍需人工复核。
- 主功能保留导轨绘制、配重、统计、直接替换/确认后替换和在线更新；退役模块不重新加入正式负载。
- 升级后输入 JJJJ 和 STABOUT，应显示 1.0.10。已加载 DLL 不能热替换，安装后须重新启动 CAD。
- 自动化验收使用自主生成图和隔离安装器；真实翻译 API、完整 CAD GUI 人工验收及本机正式安装升级未在本轮执行。
