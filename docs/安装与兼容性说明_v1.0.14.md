# 四季光伏工具箱 v1.0.14 安装与兼容性说明

- 版本 v1.0.14 / 1.0.14.0，上一稳定版 v1.0.13，正式六 DLL 支持 AutoCAD 2020 Win64 R23.1。
- 发行分类 UNSIGNED，安装器/DLL 签名预期 NotSigned，Windows 可能显示“未知发布者”；请核对本仓库下载来源和同版 SHA-256。
- 保存并备份图纸，完全退出 AutoCAD、探索者和 Core Console，运行 FourJ_PV_Toolbox_Setup_v1.0.14.exe，选择原安装范围。
- 在线清单必须声明 1 字节至 512 MiB（含上限）的 sizeBytes；异常大小在检查、网络下载及缓存复用前拒绝，失败时不替换旧文件。
- 不重置用户工程参数、API 配置或缓存；保留既有翻译、导轨、配重、统计和更新功能，退役模块不恢复。
- 升级后重新启动 CAD，在 JJJJ 和 STABOUT 确认 1.0.14；同一会话不能热替换已加载 DLL。
- 本轮不执行真实翻译 API、完整 CAD GUI 或本机正式升级，自动化不能替代这些人工验收。
