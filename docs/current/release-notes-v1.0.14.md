# 四季光伏工具箱 v1.0.14

- 修复在线更新清单缺少安装包大小、声明零字节或超限时仍被接受的问题，在线检查要求有效的正字节数且不超过 512 MiB。
- 网络下载和缓存复用前再次校验大小；下载内容短于或长于声明时，即使哈希匹配也拒绝，保留旧文件并清理临时文件。
- 保留纯本地文件清单的历史兼容，以及回退、取消、HTTPS、SHA-256 和原子下载流程；更新只从本仓库 GitHub Releases 交付完整安装包。
- 保留长英文排版、多行属性与段落格式、工程数值保护和缓存恢复；确认窗仍允许人工编辑，翻译含义需人工复核。
- 保存图纸并退出 AutoCAD、探索者和 Core Console 后安装，选择原安装范围，用户设置保留；支持 AutoCAD 2020 Win64 R23.1，安装器未做 Authenticode 签名。
- 自动化使用本地模拟传输、自主 CAD 样例及隔离安装器；未执行真实翻译 API、完整 CAD GUI 人工验收或本机正式升级。
