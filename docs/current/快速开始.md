# 四季光伏工具箱快速开始

[返回项目首页](../../README.md) · [开发入口](README.md)

本页面向正式版 v1.0.9 的首次使用者。操作入口依据正式发布说明、当前命令实现和 Bundle 清单整理；不是本轮 Windows / AutoCAD 实测报告。

## 1. 下载、校验、安装

仅 AutoCAD 2020 Win64 R23.1 属于既有核心运行验证范围。不应把其他版本的适配候选或历史测试记录视为兼容承诺。

从 [v1.0.9 发布页](https://github.com/deepfry666/fourj-pv-toolbox/releases/tag/v1.0.9) 下载 `FourJ_PV_Toolbox_Setup_v1.0.9.exe` 和 `sha256.txt`。在下载目录用 PowerShell 计算哈希，与同版校验文件中的值逐字比较：

```powershell
Get-FileHash -Algorithm SHA256 .\FourJ_PV_Toolbox_Setup_v1.0.9.exe
Get-Content .\sha256.txt
```

若不一致，不要运行安装器。安装包未做 Authenticode 签名；校验通过只说明内容匹配，不能替代发布者身份签名。

保存并备份图纸，退出 AutoCAD、探索者和 Core Console，再运行安装器。升级选择与旧版相同的安装范围，遵循安装器提示，不绕过兼容性或降级检查。安装后重启 AutoCAD，运行 `JJJJ`，用 `STABOUT` 核对版本。

## 2. 先选择一项工作

### 自动画导轨

1. 在图纸副本中，通过 `JJJJ` → **自动画导轨** 设置数量、首末总间距、贯通净距、端伸、图层、颜色和全局宽度。
2. 选择有效组件矩形轻量多段线作为图层样本，再框选范围。样本不能位于导轨输出图层。
3. 核对识别范围与提示。工具按方向、标高及空间连通性分组，导轨垂直组件长边。
4. 查看预览，按命令行提示用 `C` 确认或 `X` 取消。遇到旧导轨替换提示时，先确认选中范围和保留需求。
5. 用 `STPVRAILSTAT` 框选统计导轨总米数，复核后插入表格。

导轨功能不支持块参照或 Xref 内组件、短边布置，以及弯折、圆弧或 3D 导轨。它不生成、修改或删除尺寸标注；定位与尺寸使用 AutoCAD 原生命令完成。

### 自动布置配重与统计

1. 通过 `JJJJ` → **自动布置配重**，先识别组件阵列，检查正确／未正确识别数量及规格汇总。
2. 识别输入可包括受支持的顶层闭合二维多段线与块参照，并可多次框选去重。不要把这一能力套用到导轨功能。
3. 按排数设置配重参数，必要时为特殊阵列单独设置。使用界面中的示意图核对阵列方向、外轮廓净距 `G`、前侧中心边距 `F` 和中心间距 `S`。
4. 检查设置后生成配重。组件发生变化后，先重新识别，不继续沿用旧结果。
5. 按目的分别插入**组件阵列清单**或运行 `STPVBALLASTSTAT` 做**配重分尺寸统计**，不要混淆组件数、阵列数、榀数与单墩数。

手画圆墩或方墩需先用 `STPVBALLASTPIERRECOGNIZE` 点选确认身份，再进行配重统计。高度进入统计数据，但不参与平面绘图。自动布置不是配重承载能力计算，实际尺寸与布置需工程复核。

### 图纸文字翻译

1. 用 `STPVTRANSLATESETTINGS` 配置接口地址、模型、密钥及目标语言，按需设置术语表和缓存。接口由使用者自行提供，不承诺免费额度或所有服务兼容。
2. 确认所选文字可向该服务商发送，了解费用和数据处理政策。**“确认后替换”是在写入图纸前确认，不是发送文字前确认。**
3. 可用 `STPVTRANSLATETEST` 发送两条内置示例进行接口自检。该命令不修改图纸，但会访问配置的外部接口。
4. 首次建议使用 `STPVTRANSLATECONFIRM`，选择文字或表格，检查译文后再确认替换。熟悉流程后可用 `STPVTRANSLATE` 直接替换。
5. 人工复核术语、数字、符号、换行和排版。占位符保护、缓存及自动换行不等于译文准确性保证。

当前只提供“直接替换”和“确认后替换”，没有“原文下方插入”模式。配置不正确、接口不可达或已加载旧模块时，先排查提示，不反复操作原始图纸。

## 3. 常用命令速查

| 命令 | 用途 |
|---|---|
| `JJJJ` | 打开工具箱首页 |
| `STABOUT` | 查看工具箱版本与验证范围 |
| `STTOOLBAR` | 尝试恢复顶部 Ribbon 页签 |
| `STPVRAIL` / `STPVRAILSTAT` | 画导轨 / 导轨总米数统计 |
| `STPVBALLAST` | 打开配重页面 |
| `STPVBALLASTARRAYSETTINGS` | 特殊阵列配重参数 |
| `STPVBALLASTARRAYTABLE` | 按当前识别快照插入组件阵列清单 |
| `STPVBALLASTPIERRECOGNIZE` / `STPVBALLASTSTAT` | 确认手画单墩 / 配重统计 |
| `STPVTRANSLATESETTINGS` / `STPVTRANSLATETEST` | 翻译设置 / 外部接口自检 |
| `STPVTRANSLATECONFIRM` / `STPVTRANSLATE` | 确认后替换 / 直接替换 |
| `STPVTRANSLATEINFO` / `STPVTRANSLATELOG` | 翻译模块信息 / 诊断日志 |

独立阵列识别、支架及历史排布项目不能仅因存在源码就视为正式包命令。导轨标注命令 `STPVRAILDIM`、`STPVRAILANNOTATE`、`GDBZ` 已撤下。

## 4. 常见问题

**没有顶部工具栏？** 先用 `JJJJ` 打开工具箱，也可尝试 `STTOOLBAR`。Ribbon 创建失败不必然阻断核心命令。

**升级后仍运行旧版翻译？** 保存图纸并完全退出 AutoCAD 后重启，再用 `STPVTRANSLATEINFO` 检查已加载 DLL 的版本和路径。同一会话再次 `NETLOAD` 不会替换已经注册的旧命令。

**导轨识别不到组件？** 检查是否为样本图层上的有效矩形轻量多段线，是否误选输出图层、块或外部参照。不要为凑识别结果直接破坏原图结构。

**更新检查失败？** 可从 [正式 Releases](https://github.com/deepfry666/fourj-pv-toolbox/releases/latest) 手动下载同版安装器和校验文件。检查更新和下载需要网络，不应通过关闭 HTTPS 或哈希校验解决。

**需要反馈问题？** 先查 [问题清单](../../ISSUES.md)，在 [GitHub Issues](https://github.com/deepfry666/fourj-pv-toolbox/issues) 提供工具版本、AutoCAD 版本、命令、复现步骤及预期／实际结果。优先使用自主绘制的最小样例；日志与截图先脱敏，不上传客户图纸、API 密钥或私人配置。
