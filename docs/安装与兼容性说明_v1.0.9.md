# 四季光伏工具箱 v1.0.9 安装与兼容性说明

- 版本：v1.0.9 / 1.0.9.0；上一稳定版 v1.0.8。
- 支持 AutoCAD 2020 Win64 R23.1，正式负载为六个 DLL，发布分类 UNSIGNED，安装器与 DLL 的 Authenticode 预期为 NotSigned。
- 安装器和 DLL 没有 Authenticode 代码签名，Windows 可能显示“未知发布者”；应核对本仓库下载来源和同版 SHA-256。
- 保存并备份图纸，完全退出 AutoCAD、探索者和 Core Console，运行本仓库 Releases 中的 FourJ_PV_Toolbox_Setup_v1.0.9.exe，选择与旧版相同的安装范围。
- 本版修复长英文排版，字高最多缩小 25%，空间不足时保留该项原文并提示。块属性保持原类型，表格检查行高增长。
- 既有工程设置、API 配置和缓存文件不由安装器重置；新翻译提示使用独立缓存键，旧条目保留但不命中。
- 主工具箱保留导轨绘制、配重、统计、翻译和在线更新；导轨标注、自动排布和独立支架模块不进入正式负载。
- 在线更新从本仓库 Releases 获取 stable.json，使用完整安装器并校验 HTTPS、大小及 SHA-256；不在绘图过程中静默安装。
- 升级后在 AutoCAD 输入 JJJJ 和 STABOUT，版本应为 1.0.9。首次翻译先使用图纸副本和确认后替换，人工复核工程含义及布局。
- 自动化验收包含真实 Core Console、离线 API、四档 DPI 和隔离安装器；真实翻译 API 与完整 CAD GUI 人工验收未在本次执行。
