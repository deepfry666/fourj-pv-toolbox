# 图纸文字翻译

本目录提供可独立构建和测试的 AutoCAD 2020 模块，已接入主工具箱 Bundle。

已覆盖：

- `DBText`、`MText`、表格单元格和块属性的可写分类；
- AutoCAD `MText` 格式码、字段和工程型号/数字单位的 token 保护与恢复；
- 尺寸、多重引线、字段和 Xref 的稳定跳过原因；
- 批量翻译结果数量、空结果和状态统计。
- 非外部参照块属性的安全替换；不支持对象按类型汇总跳过原因；
- 可选术语表、当前用户译文缓存、分批请求进度、取消和失败重试。

运行 `scripts/test-drawing-translation.ps1` 进行独立核心、API 模拟、UI 测试和 DLL 构建。主工具箱首页可直接进入翻译模块；独立产物仍保留在 `work/module-builds/drawing-translation-api/StructuralToolbox.DrawingTranslation.dll`。首次运行 `STPVTRANSLATESETTINGS` 设置接口；`STPVTRANSLATE` 为直接替换，翻译和校验通过后立即写回；`STPVTRANSLATECONFIRM` 先显示原文/译文对照，用户确认后才替换。块参照本身、外部参照、字段、尺寸和多重引线保持跳过，并在命令行显示跳过原因。

总设置只保存接口地址、模型、API 密钥、目标语言、网络、术语表和缓存；“获取模型”会填充模型下拉列表。写入流程只由首页的“直接替换”或“确认后替换”决定，确认窗不再重复总设置。术语表每行使用 `原文=译文`，只作为请求提示，不会写入图纸；启用译文缓存后，缓存按接口、模型、目标语言、术语表和原文隔离，默认 30 天，可在设置窗口清空。密钥以当前 Windows 用户的 DPAPI 保护后保存在本机配置中，不写入图纸或项目。工程参数占位符只在内部请求中使用，必须在预览或写回前还原；任何未还原或损坏的 `STPV_TOKEN` 都会阻止写回。单行文字替换时转换为按原文字宽度换行的 MText；原 MText 沿用原宽度。`scripts/verify-drawing-translation-autocad.ps1` 在 `work/` 图纸副本上检查替换、自动换行及保存重开。

选择完成后命令行会显示可翻译数量、跳过数量和按对象类型汇总的跳过原因。块属性只有在非外部参照、非常量、字段未变化且写入前句柄/原文仍一致时才会处理。
多行块属性按内部完整 MText 内容读取和校验，颜色、段落等格式参与占位符保护；确认期间仅修改格式也会使旧译文跳过该属性，避免覆盖人工修改。普通单行属性仍使用其原文字内容。

译文缓存只用于加速：无效/未来时间戳、空记录及空译文自动忽略，损坏 JSON 或文件暂时锁定不会中断正常翻译。缓存保留最新的有效条目，最多 2000 条，并按实际 JSON 序列化后的 2,097,152 字符预算淘汰旧条目；单条过长或字符转义后超限时跳过缓存。工程设置和原始缓存文件不会被安装器重置。

长英文排版会先按原文字的局部方向测量实际字形，保留原宽度、对齐、方向、图层和样式，再自动换行；必要时按 5% 步长缩小字高，最低为原字高的 75%，不压扁字宽。系统检查同批已替换文字、未选中文字、块内文字、表格、尺寸/引线文字外包框及直线/直线多段线边界。单次文字最多增加到八倍原字高或原有高度；若仍放不下，保留该项原文，命令行单独报告“排版空间不足”，日志记录对应句柄。单行块属性保持属性类型，不强制转为多行；多行属性在原宽度内换行。表格会检查自动行高增长是否影响表外文字。直线边界只约束新增跨越，原本穿过文字的线保持原关系；弧线、不支持的曲线和复杂非共面模型不属于自动避让范围。

翻译请求要求简洁的工程标注，不增加解释，同时保留工程条件和警告。新提示使用独立缓存版本，旧版冗长缓存不再命中；保留旧缓存文件，无需手动清空。排版不依赖模型准确返回“短文本”，实际写入前仍执行尺寸检查。

`scripts/test-drawing-translation-layout.ps1` 可独立验证排版规则；`scripts/test-drawing-translation.ps1` 包含核心、离线 API、UI 布局和交互测试；`scripts/verify-drawing-translation-autocad.ps1` 使用自主生成的图纸验证密集排版、旋转、属性、表格、保存重开和单次撤销，产物只放在 `work/`。不调用真实翻译 API。
